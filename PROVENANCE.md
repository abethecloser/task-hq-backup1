# Provenance

**Product:** Task-HQ (renamed from “Quest” on 2026-10-17). **First customer workspace:** Quest Roofing.

Quest and Novum Bridge are separate products with independent ownership, data, identities, branding and deployment. This file records where each Quest capability came from.

## Novum Bridge

- **What was inspected:** only the top-level file listing of `~/Projects/novum-bridge` (to check whether an approved, reusable package already existed).
- **Finding:** no versioned package, published interface or license exists there (`package.json` is `"private": true`, name `novum-bridge-prototype`). There was nothing approved to reuse.
- **What was reused:** nothing. No Novum Bridge source code, credentials, data, Supabase project, branding or extension code is in Quest.
- **Runtime dependency:** none. Quest runs without Novum Bridge; Novum Bridge is unaffected by Quest.

## Developed specifically for Quest in this build

- Shared task contract and single engine (`src/core`), undo with safety checks, ownership roles (execution, next-step, decision, approver, waiting-on, watchers).
- Deterministic attention rules (`src/core/rules.ts`).
- Speed-to-lead workflow.
- Configurable Ultra Priority policy (activators, approvers, scope, durations).
- QuestBackend adapter (`chrome.storage` / `localStorage`), outbox.
- Quest Chrome extension (popup, background worker, badge, local notifications).
- Visual system (neutral whites, Quest orange) and icons (generated by `scripts/make-icons.mjs`).
- Situation composer, capability registry, Instrument Deck and local intent grammar.
- Collaborative review layer (feedback, reviewer role, invitation drafts, capture via the standard browser screen-capture API). No Novum Bridge recording or capture code was used or inspected.

## Ownership and licensing questions — agree before external commercialization

- Task-HQ was built while serving Quest Roofing, as its operations app. Before selling or licensing it to other customers, Quest Roofing and the builder/operator need a written agreement covering:
  - who owns the platform code and the brand “Task-HQ”;
  - whether Quest Roofing has rights, a license or revenue share;
  - what happens to Quest Roofing’s workspace data and its industry configuration.
- The earlier Quest prototypes (`quest-fasttrack`, `quest-hq-command-center`) were inspected for patterns only; their ownership should be confirmed before any of their ideas ship commercially.
- No Novum Bridge code is included; the Novum licensing note below still applies.

## Open licensing decision (Novum)

If any Novum Systems capability is offered to Quest in future, it should come through a versioned, permissioned interface **after** Novum Systems LLC and Quest agree on a written license or ownership position. Until then, assume no shared ownership and no license in either direction.
